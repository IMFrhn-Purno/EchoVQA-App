# EchoVQA

Multimodal Echocardiogram Visual Question Answering System

## Features

- Echocardiogram video upload
- Clinical question answering
- Optional clinical report
- View classification
- Severity prediction
- Binary prediction
- Regression estimation

## Technology

- PyTorch
- ClinicalBERT
- Streamlit
- R(2+1)D Video Encoder
